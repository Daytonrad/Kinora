## Magyar

### A böngésző megjegyzi a belépett felhasználókat
- Eddig minden új belépés kiléptette az előző felhasználót, ezért két felhasználó között csak jelszóval lehetett váltani, újra és újra. Most ha egy böngészőben egy másik felhasználó is belép, az előző nem lép ki, hanem megmarad ebben a böngészőben.
- Kijelentkezéskor a megjegyzett felhasználó veszi át a böngészőt, jelszó nélkül, a „Ki néz?” képernyőn. Ha már senki nincs megjegyezve, jön a belépés.
- A gyerekeszközök (egy profilhoz kötött belépések) ebben nem vesznek részt.
- A szerveren új API van a váltáshoz (`/api/accounts`). A „Ki néz?” képernyő, amelyen minden megjegyzett felhasználó profilja egy koppintással elérhető, egy következő kiadásban jön a webre, a TV-appokba és az iOS appba.

## English

### The browser remembers who signed in
- Until now every new sign-in signed the previous user out, so switching between two users meant typing a password again and again. Now when another user signs in on a browser, the previous one is not signed out but stays remembered on that browser.
- Signing out hands the browser to the remembered user, without a password, on the "Who's watching?" screen. With nobody left, the sign-in page comes.
- Kids devices (sign-ins locked to one profile) do not take part.
- The server has a new API for switching (`/api/accounts`). The "Who's watching?" screen with every remembered user's profiles one tap away comes to the web, the TV apps and the iOS app in a later release.

## Deutsch

### Der Browser merkt sich, wer angemeldet war
- Bisher meldete jede neue Anmeldung den vorigen Benutzer ab, ein Wechsel zwischen zwei Benutzern brauchte also immer wieder das Passwort. Meldet sich jetzt in einem Browser ein weiterer Benutzer an, bleibt der vorige gemerkt statt abgemeldet.
- Beim Abmelden übernimmt der gemerkte Benutzer den Browser, ohne Passwort, auf dem Bildschirm „Wer schaut?“. Ist niemand mehr gemerkt, kommt die Anmeldung.
- Kindergeräte (an ein Profil gebundene Anmeldungen) sind nicht dabei.
- Der Server hat eine neue API zum Wechseln (`/api/accounts`). Der Bildschirm „Wer schaut?“ mit den Profilen aller gemerkten Benutzer, jeweils mit einem Tippen erreichbar, kommt in einer späteren Version ins Web, in die TV-Apps und in die iOS-App.
