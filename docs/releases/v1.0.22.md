## Magyar

### Könyvtárak felhasználónként
- Az Admin → Felhasználók oldalon minden nem admin fióknál beállítható, mely könyvtárakat láthatja. Alapból mindet látja, mint eddig.
- A korlátozott fiók csak a kipipált könyvtárak címeit látja: kezdőlap, könyvtárlista, keresés, gyűjtemények, ajánlások, lejátszás, letöltés és watch party. Más könyvtár címe közvetlen hivatkozással sem nyílik meg.
- A beállítás a fiók összes profiljára érvényes. Az adminok mindig mindent látnak.
- Jó például vendég- vagy demófiókhoz, ami csak egy kijelölt könyvtárat lát.

## English

### Libraries per user
- Admin → Users can set, for every non-admin account, which libraries it may see. By default it sees all of them, as before.
- A limited account sees titles only from the ticked libraries: home, library list, search, collections, recommendations, playback, downloads and watch parties. A title from another library does not open even by direct link.
- The setting applies to every profile of the account. Admins always see everything.
- Useful for a guest or demo account that should see only one chosen library.

## Deutsch

### Bibliotheken pro Benutzer
- Unter Admin → Benutzer lässt sich für jedes Konto ohne Adminrechte festlegen, welche Bibliotheken es sehen darf. Standardmäßig sieht es alle, wie bisher.
- Ein eingeschränktes Konto sieht nur Titel aus den angehakten Bibliotheken: Startseite, Bibliotheksliste, Suche, Sammlungen, Empfehlungen, Wiedergabe, Downloads und Watch-Partys. Ein Titel aus einer anderen Bibliothek öffnet sich auch über einen direkten Link nicht.
- Die Einstellung gilt für alle Profile des Kontos. Admins sehen immer alles.
- Praktisch für ein Gast- oder Demokonto, das nur eine bestimmte Bibliothek sehen soll.
