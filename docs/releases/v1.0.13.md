## Magyar

### Egy film, több verzió – IMDb alapján
- Az azonos IMDb-azonosítójú filmek mappától és könyvtártól függetlenül egy kártyaként jelennek meg („2 verzió” jelvénnyel) a listákban, a keresésben, a Folytatásban, az ajánlásokban és az okos gyűjteményekben.
- Az IMDb-azonosító forrása: NFO-fájl (`<imdbid>`, `<uniqueid type="imdb">`), `{imdb-tt…}` címke a fájl- vagy mappanévben, illetve a TMDB-egyeztetés. A már meglévő filmek a következő metaadat-frissítéskor kapják meg.
- Verzióválasztó a film oldalán: felbontás, HDR, kodek, hang, méret, és ha a fájlnévben szerepel, a változat neve (`{edition-…}`, Director's Cut, Extended, Theatrical…).
- A film oldala a legutóbb nézett verzión nyílik meg; a megnézve-jelölés, a kedvenc, a csillagok és a lejátszási pozíció minden verzióra érvényes.

### Feliratletöltés (OpenSubtitles)
- „Felirat keresése…” a lejátszó felirat menüjében (teljes képernyőn is) és a film oldalán a „Több” menüben.
- A találatok sorrendje: a profil nyelvei, a pontosan erre a fájlra készült feliratok (hash-egyezés), a nem gépi fordítások, a megbízható feltöltők, végül a letöltésszám.
- A letöltött felirat azonnal bekapcsol; a Kinora jelzi, hány letöltés maradt mára.
- A feliratok az adatkönyvtárba kerülnek (`<data>/subtitles/`), a médiamappába a Kinora továbbra sem ír.
- Beállítás: Admin → Metaadatok → OpenSubtitles (API-kulcs, opcionálisan felhasználónév és jelszó), vagy a `KINORA_OPENSUBTITLES_KEY`, `KINORA_OPENSUBTITLES_USER`, `KINORA_OPENSUBTITLES_PASS` környezeti változók.

## English

### One film, several versions – grouped by IMDb ID
- Movies with the same IMDb ID show as one card ("2 versions" badge) in lists, search, Continue watching, recommendations and smart collections, whatever folder or library they are in.
- The IMDb ID comes from the NFO file (`<imdbid>`, `<uniqueid type="imdb">`), an `{imdb-tt…}` tag in the file or folder name, or the TMDB match. Existing movies get it on the next metadata refresh.
- Version picker on the film page: resolution, HDR, codec, audio, size, and the cut name when the file name has one (`{edition-…}`, Director's Cut, Extended, Theatrical…).
- The film page opens on the version you watched last; watched state, favorite, stars and playback position apply to every version.

### Subtitle download (OpenSubtitles)
- "Search subtitles…" in the player's subtitle menu (works in full screen too) and in the film page's "More" menu.
- Results are ordered by the profile's languages, subtitles made for exactly this file (hash match), human translations, trusted uploaders, then download count.
- A downloaded subtitle is turned on right away; Kinora shows how many downloads are left today.
- Subtitles are stored in the data folder (`<data>/subtitles/`); Kinora still never writes to the media folders.
- Setup: Admin → Metadata → OpenSubtitles (API key, optionally username and password), or the `KINORA_OPENSUBTITLES_KEY`, `KINORA_OPENSUBTITLES_USER`, `KINORA_OPENSUBTITLES_PASS` environment variables.
