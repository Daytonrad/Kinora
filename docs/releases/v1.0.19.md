## Magyar

### Felfedezés a kliens nyelvén
- A Felfedezés címei, leírásai és műfajai mostantól a kliens nyelvén jelennek meg (angol vagy német iOS appban és webes felületen is), nem mindig a szerver metaadat-nyelvén. Az igénylések továbbra is a szerver metaadat-nyelvét használják.

### Admin menü finomítások
- Az összecsukott csoport alatt már nem marad üres sáv az oldalsávban.
- Telefonon a kiválasztott csoport gombja visszafogott kiemelést kapott; borostyánszín csak az aktív oldalt jelöli.

## English

### Discover in the client's language
- Discover titles, overviews and genres now follow the client's language (English or German iOS app and web client too) instead of always using the server's metadata language. Requests still use the server's metadata language.

### Admin menu polish
- A folded group no longer leaves an empty strip in the sidebar.
- On phones the chosen group's button has a quieter highlight; amber marks only the active page.
