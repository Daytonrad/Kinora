## Magyar

### Javítás: a „Frissítés most” gomb Windowson (1.1.3)
- Az irányítópult **Frissítés most** gombja Windowson nem csinált semmit. Mostantól a szerver saját maga frissít, PowerShell nélkül: futás közben letölti és ellenőrzi (SHA-256) az új kiadást, majd leáll, elmenti az adatbázist és a régi programfájlokat, a helyükre teszi az újakat, és a Windows szolgáltatáskezelője újraindítja.
- Az új verzió próbaidőn van: ha háromszor egymás után nem indul el, vagy 3 percen belül nem kezd kiszolgálni, a régi program és adatbázis magától visszakerül. Az eredmény az `update.log`-ba kerül, és az irányítópult mutatja.
- Erre a verzióra még a régi módon kell frissíteni (éjszakai automatikus frissítés vagy `update.ps1`); a gomb a következő kiadástól működik.

## English

### Fix: the "Update now" button on Windows (1.1.3)
- The dashboard's **Update now** button did nothing on Windows. The server now updates itself without PowerShell: while it keeps serving it downloads and verifies (SHA-256) the new release, then stops, backs up the database and the old program files, puts the new ones in place and is restarted by the Windows service manager.
- The new version is on probation: if it fails to start three times in a row, or does not serve within 3 minutes, the old program and database are put back automatically. The outcome goes to `update.log` and the dashboard shows it.
- To get this version, update the old way (the nightly automatic update or `update.ps1`); the button works from the next release on.
