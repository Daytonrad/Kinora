## Magyar

### Javítás: másfél perc után megálló lejátszás Windows-szerveren (újra)
- Az 1.1.4 nem szüntette meg a hibát: a lejátszó kb. másfél perc után úgy állt meg, mintha vége lenne a résznek. Windowson az ffmpeg mostantól nem átnevezéssel cseréli a lejátszási listát (ez Windowson elakadhat, ha valaki épp olvassa a fájlt), hanem helyben írja újra; a szerver a félig megírt utolsó sort nem adja ki.
- A napló minden ffmpeg-futás végén rögzíti az időt, a kész szegmensek számát és az ffmpeg utolsó üzenetét (`ffmpeg done`).

## English

### Fix: playback stopping after a minute and a half on a Windows server (again)
- 1.1.4 did not cure it: the player stopped about a minute and a half in, as if the episode had ended. On Windows ffmpeg no longer replaces the playlist by a rename (which can fail on Windows while the file is being read) but rewrites it in place; the server never serves a half-written last line.
- The log records, at the end of each ffmpeg run, the time taken, the number of segments and ffmpeg's last message (`ffmpeg done`).
