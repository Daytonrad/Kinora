## Magyar

### Új: frissítés a webes felületről Windowson
- Windowson a szervert már nem csak az `update.ps1`-gyel lehet frissíteni: ha van újabb kiadás, az **Admin → Irányítópult** verziósora alatt megjelenik a **Frissítés most** gomb.
- Megerősítés után a szerver a háttérben elindítja a megszokott frissítést: SHA-256 ellenőrzés, a program és az adatbázis mentése, csere, állapotellenőrzés, és ha az új verzió nem indul el, **automatikus visszaállás**. A szolgáltatás kb. egy percre leáll; az oldal megvárja az új verziót, majd magától újratölt.
- Akkor is működik, ha az éjszakai automatikus frissítés ki van kapcsolva. Ha az előző frissítés nem sikerült, az irányítópult megmutatja a hibaüzenetet az `update.log`-ból.
- Ez az első olyan kiadás, amely tartalmazza a gombot: a v1.0.17-ről még egyszer a megszokott módon (éjszakai frissítés vagy `update.ps1`) kell frissíteni, utána már a felületről is megy.

### Admin menü
- Az admin oldalsáv csoportjai (Könyvtár, Hozzáférés, Beszerzés, Rendszer) összecsukhatók, mellettük az oldalak száma; a böngésző megjegyzi, melyik van összecsukva. Az aktuális oldal csoportja mindig nyitva marad.
- Telefonon a tizenöt elemes görgetősáv helyett két sor: fent a csoportok, alatta a kiválasztott csoport oldalai.

## English

### New: update from the web interface on Windows
- On Windows the server no longer needs `update.ps1` to update: when a newer release exists, an **Update now** button appears under the version line on **Admin → Dashboard**.
- After a confirmation the server starts the usual update in the background: SHA-256 check, backup of the program and the database, swap, health check, and an **automatic rollback** if the new version does not start. The service stops for about a minute; the page waits for the new version and reloads by itself.
- It works even with the nightly automatic update turned off. When the previous update failed, the dashboard shows its error from `update.log`.
- This is the first release with the button: from v1.0.17 update once more the usual way (nightly update or `update.ps1`); after that the web interface does it too.

### Admin menu
- The admin sidebar's groups (Library, Access, Acquisition, System) fold, with their page count beside them; the browser remembers which are folded. The current page's group always stays open.
- On phones two rows replace the fifteen-item strip: the groups on top, the chosen group's pages below.
