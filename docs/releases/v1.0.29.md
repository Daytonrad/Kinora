## Magyar

### Egy sorozat, egy kártya
- Ha egy sorozat két példányban van meg ugyanabban a könyvtárban – a letöltés eredeti mappájában és a sorozat saját mappájába importált másolatként –, eddig két kártya jelent meg. Most a TMDB-azonosító alapján egy sorozat lesz belőlük, ahogy a filmek verziói is egy kártyát adnak IMDb-azonosító alapján. A saját mappás példány marad meg.
- Egy epizód két fájlja egyszer jelenik meg az évadlistában, a „következő rész”-nél és a számlálóban.
- Ha a metaadat-letöltés talál egy új duplikált sorozatot, a szerver egyszer újra átvizsgálja a könyvtárat, így az összevonás azonnal látszik.

## English

### One show, one card
- When a show exists twice in the same library – in the download's own folder and as the copy imported into the show's folder – it used to show up as two cards. Copies matched to the same TMDB show are now one show, just as film versions are one card by IMDb id. The copy with the show's own folder is kept.
- Two files of the same episode appear once in the season list, in "next episode" and in the episode count.
- When metadata finds a new duplicate show, the server scans the library once more, so the join shows up right away.

## Deutsch

### Eine Serie, eine Karte
- Liegt eine Serie zweimal in derselben Bibliothek – im Ordner des Downloads und als Kopie im eigenen Serienordner –, erschienen bisher zwei Karten. Kopien, die derselben TMDB-Serie zugeordnet sind, werden jetzt zu einer Serie, so wie Filmversionen anhand der IMDb-ID eine Karte bilden. Die Kopie mit eigenem Serienordner bleibt erhalten.
- Zwei Dateien derselben Folge erscheinen in der Staffelliste, bei „nächste Folge“ und in der Folgenzahl nur einmal.
- Findet der Metadatenabruf eine neue doppelte Serie, scannt der Server die Bibliothek noch einmal, damit die Zusammenführung sofort sichtbar ist.
