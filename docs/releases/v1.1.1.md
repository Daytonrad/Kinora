## Magyar

### Biztonsági javítás (1.1.1)
- A `gorilla/websocket` könyvtár frissítve a GO-2026-6278 javítására (gyenge véletlenszám a WebSocket maszkkulcsához). A watch party és a Jellyfin-kompatibilis API WebSocketje használja.
- Az 1.1.0-hoz nem készült Docker-image: a Dockeres telepítések ezzel a kiadással kapják meg az alábbi újdonságokat is.

### Váltás Jellyfinről, Sonarrról, Radarrról és Prowlarrról
- **Admin → Import → Jellyfin:** felhasználók (jelszó nélkül, egyszer használható jelszóbeállító linkkel), megnézett állapot, folytatási pozíció, kedvencek és utolsó lejátszás.
- Párosítás fájlútvonal (útvonal-leképezéssel), TMDB/IMDb/TVDB azonosító, epizódnál évad és epizódszám alapján.
- Előnézet: mit párosított, mit nem, és miért. Csak jóváhagyás után ír, újrafuttatva nem duplikál, a jelentés CSV-ben letölthető.
- **Admin → Import → Sonarr / Radarr / Prowlarr:** figyelt sorozatok és filmek, minőségprofilok, indexerek, letöltőkliensek és gyökérmappák, ugyanígy előnézettel. Részletek: [docs/IMPORT.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/IMPORT.md).

### Jellyfin-kompatibilis API (alapból kikapcsolva)
- Meglévő Jellyfin-kliensek csatlakozhatnak a Kinorához, külön porton (`KINORA_JELLYFIN_COMPAT=1` és Admin → Beállítások).
- A Kinora jogosultságai itt is érvényesek: gyerekprofil, könyvtár-korlátozás. Quick Connect profil- és PIN-választással.
- Kodi + JellyCon-nal kipróbálva; mi működik és mi nem: [docs/JELLYFIN_COMPAT.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/JELLYFIN_COMPAT.md).

### Kezdő beállítás varázslóval
- Az admin fiók után: médiamappák (mappaválasztóval), TMDB-kulcs magyarázattal, hardveres gyorsítás tesztje, letöltőkliens és indexer, távoli elérés (Tailscale, Cloudflare Tunnel, reverse proxy), összefoglaló.
- Minden lépés kihagyható; ami kimaradt, az irányítópult felajánlja, a varázsló az Admin → Beállítások oldalról újra megnyitható.

### Offline letöltés az appokban
- **Android:** a letöltés a rendszer letöltéskezelőjével, a háttérben történik; szerver nélkül a szerverlistán a „Letöltések offline” részből játszható le. Ez a rész új, készüléken még nem próbáltuk ki.
- **iOS:** ha az app szerver nélkül indul, a letöltéseket mutatja.
- A letöltések profilhoz kötöttek: offline az utoljára használt profil letöltései látszanak, gyerekprofil más profil letöltését nem látja. Az offline megnézett pozíció a következő csatlakozáskor a szerverre kerül.

### Gyorsabb párhuzamos kiszolgálás
- A tétlen adatbázis-kapcsolatok nyitva maradnak, és az SQLite a globális memóriastatisztika-zár nélkül fordul. Párhuzamos kéréseknél ez többszörös áteresztőképességet adott.
- Mérés a Jellyfin 12.4.0-val szemben, ugyanazon a gépen és könyvtáron: [docs/BENCHMARKS.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/BENCHMARKS.md).

### Biztonság és megbízhatóság
- CSRF-védelem a sütis munkamenetekhez; a belső hibák részletei nem jutnak ki; jogosultsági rések bezárva.
- Közös letöltési feladatok, korlátos sorok, fiókonkénti átkódolási limit; a háttérfolyamatok túlélik a váratlan hibákat.
- Újabb verzió által írt adatbázist a szerver nem nyit meg.
- A fuzz-tesztek által talált hibák javítva a fájlnév-, release- és Cardigann-elemzőkben.

### Közreműködés
- Új: CONTRIBUTING.md, SECURITY.md, issue- és PR-sablonok, CHANGELOG.md.

## English

### Security fix (1.1.1)
- The `gorilla/websocket` library is updated to the fix for GO-2026-6278 (weak random numbers for the WebSocket mask key). The watch party and the Jellyfin-compatible API use its WebSocket.
- No Docker image was built for 1.1.0: Docker installs get the changes below with this release.

### Switching from Jellyfin, Sonarr, Radarr and Prowlarr
- **Admin → Import → Jellyfin:** users (without passwords, with a one-time set-password link), watched state, resume positions, favourites and last played.
- Matching by file path (with path mapping), TMDB/IMDb/TVDB id, and season and episode number.
- Preview: what matched, what didn't and why. Writes only after approval, does not duplicate when run again, and the report can be downloaded as CSV.
- **Admin → Import → Sonarr / Radarr / Prowlarr:** monitored series and films, quality profiles, indexers, download clients and root folders, with the same preview. Details: [docs/IMPORT.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/IMPORT.md).

### Jellyfin-compatible API (off by default)
- Existing Jellyfin clients can connect to Kinora on a separate port (`KINORA_JELLYFIN_COMPAT=1` and Admin → Settings).
- Kinora's permissions apply: kids profiles, library restrictions. Quick Connect with profile and PIN choice.
- Tried with Kodi + JellyCon; what works and what doesn't: [docs/JELLYFIN_COMPAT.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/JELLYFIN_COMPAT.md).

### Setup wizard
- After the admin account: media folders (with a folder picker), TMDB key with an explanation, hardware acceleration test, download client and indexer, remote access (Tailscale, Cloudflare Tunnel, reverse proxy), summary.
- Every step can be skipped; the dashboard offers what was left out, and the wizard can be opened again from Admin → Settings.

### Offline downloads in the apps
- **Android:** downloads run in the background through the system's download manager; without the server they play from "Offline downloads" on the server list. This part is new and has not been tried on a device yet.
- **iOS:** when the app starts without the server, it shows the downloads.
- Downloads belong to profiles: offline the last profile's downloads show, and a kids profile never sees another profile's. Positions watched offline reach the server on the next connection.

### Faster concurrent serving
- Idle database connections stay open, and SQLite is built without its global memory-statistics lock. Under concurrent requests this gave several times the throughput.
- Measured against Jellyfin 12.4.0 on the same machine and library: [docs/BENCHMARKS.md](https://github.com/ScotyLucas/Kinora/blob/main/docs/BENCHMARKS.md).

### Security and reliability
- CSRF protection for cookie sessions; internal error details no longer leak; permission gaps closed.
- Shared download jobs, bounded queues, a per-account transcode limit; background loops survive unexpected errors.
- The server refuses a database written by a newer version.
- Bugs found by fuzzing fixed in the file name, release and Cardigann parsers.

- New: CONTRIBUTING.md, SECURITY.md, issue and PR templates, CHANGELOG.md.
